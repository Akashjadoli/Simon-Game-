# Simon Game 🎮

A memory-based color sequence game built with HTML, CSS & Vanilla JavaScript.

## How To Play
- Press any key to start the game
- Watch the color sequence carefully
- Click the buttons in the same order
- Each round adds one more color to the sequence
- Wrong click = Game Over!

## Features
- Increasing difficulty each round
- Score tracking
- Breathing animation on Game Over
- Restart with Enter key

## Tech Stack
- HTML
- CSS
- Vanilla JavaScript
